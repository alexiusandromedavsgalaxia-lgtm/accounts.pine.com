PINE ACCOUNT · PRIVACIDAD

Privacidad.

Información clara sobre los datos que Pine Account utiliza para mantener tu cuenta y prestar sus funciones.

Pine Account · 2026

1. Qué datos se gestionan

Pine Account puede almacenar datos necesarios para crear y mantener tu identidad, como tu nombre, dirección de correo electrónico, información de autenticación, sesiones y datos que decidas guardar mediante las funciones de la plataforma.

2. Autenticación y sesiones

Las contraseñas no se almacenan como texto plano. El sistema utiliza derivación criptográfica con una sal individual para comprobarlas. Las sesiones se representan mediante tokens cuyo valor derivado se almacena en la base de datos.

3. Datos de cuenta y sincronización

Los datos guardados mediante las funciones de cuenta se vinculan al identificador de tu cuenta. Las consultas autenticadas se limitan al usuario de la sesión activa, de modo que una cuenta no debería recibir los registros pertenecientes a otra.

4. Developer Account

Si creas un Developer Account, pueden almacenarse datos como nombre, correo, empresa, sitio web, descripción, plan, estado, credenciales de desarrollador y fechas asociadas. Las credenciales deben mantenerse privadas.

5. Cookies y almacenamiento

Pine utiliza una cookie de sesión llamada pine_session para mantener la sesión iniciada. La cookie está configurada para reducir su exposición al código de las páginas y para transmitirse de forma segura.

6. Conservación y cambios

Los datos se conservan mientras sean necesarios para proporcionar las funciones correspondientes, sujeto a la configuración y evolución del servicio. Esta información puede actualizarse cuando cambie la plataforma.

7. Contacto

Si necesitas información adicional sobre privacidad o sobre los datos asociados a tu cuenta, utiliza los canales de contacto disponibles en Pine.
